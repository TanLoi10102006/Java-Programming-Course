# Java-Programming-Course
## 📚 Giới thiệu
Khoá học này cung cấp kiến thức nền tảng về lập trình Java, từ cú pháp cơ bản đến các khái niệm nâng cao như OOP, Collections, và xử lý ngoại lệ.  
Tài liệu và mã nguồn trong repo được sắp xếp theo từng bài học để dễ theo dõi.

## 📂 Nội dung khoá học
1. **Giới thiệu Java**
   - Lịch sử và ứng dụng
   - Cài đặt JDK và IDE
2. **Cú pháp cơ bản**
   - Biến, kiểu dữ liệu, toán tử
   - Nhập/xuất dữ liệu
3. **Cấu trúc điều khiển**
   - If/else, switch
   - Vòng lặp for, while, do-while
4. **Phương thức và hàm**
   - Khai báo, tham số, giá trị trả về
   - Phạm vi biến
5. **Lập trình hướng đối tượng (OOP)**
   - Class, object
   - Tính đóng gói, kế thừa, đa hình
6. **Xử lý ngoại lệ**
   - Try/catch/finally
   - Tạo ngoại lệ tùy chỉnh
7. **Collections và Generics**
   - ArrayList, HashMap, Set
   - Generic methods & classes
8. **Làm việc với file**
   - Đọc/ghi file
